# OOP-project

## Автор: Шарафутдинова Азалия, группа ТОП-202Б, УУНиТ

## Идея проекта
Удобный веб-сервис, который помогает за пару кликов выбрать фильм или сериал на вечер по конкретным параметрам (свободное время, компания, настроение и доступные подписки), чтобы не листать Кинопоиск по полчаса.

## Файлы в репозитории

kino_verified_data.csv — реальная статистика рынка онлайн-кинотеатров РФ. (Настоящие данные (ТМТ Консалтинг, ICMR, ВЦИОМ)).

user_survey.csv — данные опроса 1 500 зрителей: возраст, количество платных подписок, основной онлайн-кинотеатр, частота просмотров в неделю, среднее время на поиск фильма и готовность пользоваться сервисом подбора. (Синтетические данные)

watch_history.csv — лог 3 000 сессий вечернего просмотра: дата, день недели, время суток, компания, настроение, доступное время, длительность выбранного фильма и факт досмотра до конца. (Синтетические данные)
